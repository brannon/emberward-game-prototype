Controls and browser saves

Arrows / WASD: move. Z / Enter / Space: confirm. X / Escape / Backspace: back. C: camp. M: mute. F5: save. F9: load. Shortcuts apply while the game has focus. Tab moves between page controls. Touch controls also work with a mouse.

Save while exploring or camping; load on the title screen, while exploring, or in camp. Wait for confirmation before closing the page. There is no autosave. Saves belong to this browser and site, not your GitHub account. Private browsing, clearing site data, or storage eviction can erase them.

Export downloads a portable save file. Import validates and loads a file, replacing the current journey; then choose Save to keep it in this browser. Export/import also works with the native game.

Sound starts after Play. If your browser blocks it, click the game to resume sound. The game and sound pause when you switch tabs or windows. Fullscreen is optional; unsupported browsers can play in the normal page.
